# Posting pack template

Deliver one with every finished video (model: `tools/jetup-5-checks-v5/posting-pack-v5.1.md` in the mtgtribe repo).
Everything goes in code blocks so MTG can copy it in one tap. No em or en dashes anywhere. Check every link on the
live site before handing it over.

```
# [Video title]: posting pack ([date], awaiting MTG's approval)

File: [name].mp4 ([16:9 or 9:16], [resolution], [fps], [length]). Thumbnail: [name].jpg.
Goal: [primary goal] (+ [secondary]). Stage: [Discover / Learn / Trust / Decide / Grow].
Main address: [the one page this video sends people to].

## Title (+ 2 alternates for a re-post or test)

## YouTube description
Line 1 to 2: the hook as a question, then the main link.
Then: what they will learn (2 to 3 lines), chapters, then:

🔁 Share it with [the specific person from the video].

#[3 hashtags]

## Tags (YouTube)

## Pinned comment
The video's question + the main link + one line inviting answers.

## TikTok and Instagram caption
Hook line, the question, "link in bio", 3 to 5 hashtags.

## Facebook post
A real question tied to the content (no "comment YES if"), the main link, the tribe link.

## WhatsApp tribe message
A friendly intro, the link, a question to discuss in the group.

## WhatsApp status text (for MTG and for members to share)
One line hook + link. Under 60 seconds of video.

## Thumbnail text (2 to 4 words)

## End screen and cards
Which video or playlist comes next, and the subscribe button.

## Publish checklist
- [ ] MTG approved the final video
- [ ] Every link opened and checked on the live site (referral parameters intact)
- [ ] Captions match the final audio
- [ ] No personal or sensitive data in any frame or the thumbnail
- [ ] Closing track placed, speech clear
- [ ] Pinned comment ready to post in the first minute
```
