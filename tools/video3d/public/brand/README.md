# MTG's photos

`npm install` and `npm run setup` copy these here from the `brand-assets` branch (folder `brand/`):

- `mtg-profile-photo.png`: the full photo, shown large in every video (`PhotoCard`).
- `mtg-profile-face-crop.png`: only for the tiny brand bar icon.

They are not committed here, so the `brand-assets` branch stays the one source of truth.
